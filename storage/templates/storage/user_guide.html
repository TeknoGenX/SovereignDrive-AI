Bantuan / Panduan Pengguna

Panduan Pengguna SovereignDrive AI

1. Mengunggah File

Klik tombol "Upload" pada dashboard untuk memilih file dari perangkat Anda. Sistem mendukung berbagai format file termasuk dokumen, gambar, dan PDF.

2. Manajemen Folder

Gunakan tombol "Folder Baru" untuk mengorganisir data Anda. Anda dapat membuat struktur folder berjenjang (folder di dalam folder) tanpa batasan kedalaman.

3. Pencarian Cerdas (AI Search)

Sistem secara otomatis mengekstrak teks dari gambar dan PDF hasil scan. Cukup ketikkan kata kunci di kolom pencarian dashboard untuk menemukan dokumen Anda berdasarkan isinya.

4. Berbagi File & Folder

Anda dapat membagikan file secara publik atau melalui link rahasia. Gunakan fitur "Share" untuk mengatur izin akses atau membuat link yang dapat diunduh orang lain.
