Kebijakan Privasi

Terakhir diperbarui: {{ today|date:"d F Y" }}

1. Komitmen Kami terhadap Privasi

SovereignDrive AI berkomitmen untuk melindungi privasi data Anda. Sebagai platform "Private Cloud", kami memastikan bahwa data Anda hanya dapat diakses oleh Anda dan pihak yang Anda izinkan melalui enkripsi AES-256 yang kuat.

2. Data yang Kami Kumpulkan

Kami hanya mengumpulkan informasi minimal yang diperlukan untuk menyediakan layanan, termasuk:

  • Informasi akun (nama, email) dari SSO atau pendaftaran manual.
  • Metadata file untuk keperluan organisasi dan pencarian.
  • Log aktivitas (Audit Log) untuk keamanan akun Anda.

3. Penggunaan Data

Data Anda digunakan secara eksklusif untuk:

  • Menyediakan akses ke penyimpanan cloud Anda.
  • Proses AI Indexing agar file Anda dapat dicari secara cerdas.
  • Menerapkan fitur DLP (Data Loss Prevention) untuk melindungi dokumen Anda.

4. Keamanan

Kami menggunakan enkripsi tingkat militer dan tidak memiliki akses ke kunci enkripsi pribadi Anda jika dikonfigurasi demikian. Data Anda disimpan di infrastruktur yang aman dan terpantau 24/7.
