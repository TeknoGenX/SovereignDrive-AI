## 🛠️ Alat & Teknologi yang Digunakan
1. **Bahasa:** Python 3.12+
2. **Framework:** Django 5.x, DRF, Celery.
3. **Database:** PostgreSQL, Redis, Elasticsearch.
4. **Security:** AES-256 GCM, Bcrypt, JWT.
5. **AI/ML:** Tesseract OCR, NLTK, PyMuPDF.
6. **Infrastruktur:** Docker, WhiteNoise, Gunicorn.
